# Edge 商店上架材料（Microsoft Edge Add-ons）

> 提交入口：https://partner.microsoft.com/dashboard/microsoftedge
> 流程概览：注册合作伙伴中心开发者账号（免费，个人账号即可）→ 提交 zip → 填商店信息 → 审核（一般几个工作日，权限较宽时可能更久）→ 上架。

## 第 0 步：打包

```bash
node tools/package.js
# 产出 dist/wangshen-autofill-v1.2.0.zip（只含运行必需文件，manifest 在 zip 根目录）
```

## 第 1 步：注册开发者账号（只有你能做）

1. 用微软账号登录上面的提交入口。
2. 选择「个人」账号类型（个人免费；公司账号同样免费但需要企业验证）。
3. 完成身份验证（邮箱 + 手机号）。

## 第 2 步：提交新扩展

上传 zip 后，按下面填写：

| 项目 | 内容 |
|---|---|
| 显示名称 | 网申自动填写助手 |
| 简短说明 | 简历字段库 + 一键自动填网申表单 + AI 起草开放题，数据只存本机 |
| 类别 | 效率 / 生产力 |
| 隐私政策 URL | **必填**（见下方说明），把 `PRIVACY.md` 内容发布后填网址 |
| 网站地址 | 可选（GitHub 仓库或个人主页） |
| 产品 Logo | `icons/icon128.png`（已含在 zip，商店页自动使用；如单独索要就用它） |

### 详细描述（直接粘贴）

```
把简历信息一次性录入字段库，之后在任意招聘网申页面：
· 短字段（姓名/电话/学校/专业…）一键自动填充，兼容 React/Vue 表单
· 下拉框/单选自动匹配选项（支持 CET-4↔四级 等同义写法）
· 长文本点选填入，开放题（"为什么选择我们"）可用智谱 GLM 按你的素材起草
· 简历 PDF 一键导入（文本/扫描件双路识别），先校对再入库
· 多档案切换（互联网/央国企全字段 51 项模板）、敏感信息 •••• 遮挡
· 投递台账自动记录、导出 CSV
· 检测到上传控件时提醒该传哪份材料

隐私：所有数据只存本机浏览器，不上传任何服务器；AI 功能仅在你主动点击时
把简历文本/题目素材发送到智谱开放平台(open.bigmodel.cn)。插件永不自动点击
"提交/投递"按钮，最后一步永远由你本人确认。

需要自备智谱 API Key（open.bigmodel.cn 免费注册领取）。
```

### 权限用途说明（审核员可能要求逐条解释，提前备好）

```
· content_scripts 匹配 <all_urls>：插件定位是"任意招聘网站通用"，无法预先枚举
  所有招聘站点域名；检测与填充逻辑只在用户主动点击"一键填充/填入"时执行。
· tabs：读取当前活动标签页的 URL/标题，用于平台识别（Moka/国聘/通用）与投递台账记录。
· storage：本地保存简历字段库、档案、设置与台账，数据不出本机。
· downloads：仅用于把用户点击导出的台账 CSV / 档案备份 JSON 保存到本地。
· host_permissions open.bigmodel.cn：唯一的对外请求，用户主动触发的智谱 AI 调用。
· sidePanel：侧边栏界面本体。
```

## 第 3 步：商店素材

- **截图 3~5 张**（1280×800 或 640×480，PNG/JPG）：建议截 ①侧边栏字段库 ②一键填充+复查清单 ③PDF 校对界面 ④开放题 AI 起草。截图前先在字段库里填入**虚构测试数据**（不要用真实身份证/手机号）。
- 商店页语言选中文（简体）。

## 第 4 步：隐私政策 URL

`PRIVACY.md` 已写好，二选一：
1. 放进你的 GitHub 仓库开 GitHub Pages（和 personal-site 一起部署最省事）；
2. 或发布成一篇公开的博客/语雀/飞书文档。
把可公开访问的网址填到提交流程的「隐私政策 URL」。

## 注意事项

- **审核**：内容脚本 `<all_urls>` 属于宽权限，审核可能比一般扩展慢（几天到一两周），被拒可按驳回意见在"权限说明"里补充解释后重新提交。
- **本插件不含任何个人信息**：打包内容只有代码和图标；商店截图和描述里也不要放真实简历数据。
- **Chrome 用户**：Edge 商店只服务 Edge；要覆盖 Chrome 需另在 Chrome Web Store（一次性 $5 开发者注册费）提交同一个 zip。
- 版本更新：改完代码 → `node tools/package.js` → 合作伙伴中心提交新版本。
