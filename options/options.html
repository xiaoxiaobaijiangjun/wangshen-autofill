网申自动填写助手 · 设置

① 智谱 GLM API

服务商固定为智谱（open.bigmodel.cn）。Key 只保存在本机 chrome.storage.local，不进代码、不上传其他服务器。PDF 视觉提取按页计费，文本模式优先。

② 填充设置

label 与同义词表匹配得分 ≥ 阈值才自动填（调低更激进，调高更保守）

③ 简历 PDF 导入

流程：PDF → pdf.js 抽文本 → 不足 200 字或乱码率超 30% 自动改走 GLM 视觉模式（逐页）→ 提取结果先进入上方校对区，人工确认后才写入档案。禁止跳过校对直接入库。

④ 模板管理

全字段模板（互联网 + 央国企合并，51 字段）：新建档案（侧边栏顶部「＋」）默认带全部字段，有值就填、没值自动跳过；字段可在档案里随意增删改。

⑤ 数据与隐私

备份包含全部档案和字段值，不含 API Key。换电脑或重装浏览器前建议先导出。

所有简历数据、档案、台账只存在本机浏览器的 chrome.storage.local 中；唯一的对外网络请求是你主动触发的 智谱 AI 调用（内容：简历文本或题目+素材段落），请求只发往 open.bigmodel.cn。 插件永不自动点击任何「提交/投递」类按钮，最后一步永远由你本人操作。
